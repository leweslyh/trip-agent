# AI 出行助手 · 课程说明

## 课程简介

本课程是一次「大模型应用开发」实战练习：学生在 CodeBuddy 辅助下，从零完成一个可运行的 **AI 出行助手** 前端项目。课程强调从需求描述到可交付作品的完整过程，而不是单纯的代码编写。

## 学习目标

- 学会把自然语言需求拆解为可执行的功能点，并用提示词驱动大模型辅助设计与编码。
- 理解智能体（Agent）的基本工作方式：意图识别、工具定义（Function Calling）、多轮工具调用与结果回填。
- 掌握前端调用大模型 API 与地图服务 API 的方法，理解 Key 的申请、使用与保密规范。
- 学会用版本库管理作品：主分支保留课程说明，学生作品各自作为独立分支交付。
- 建立工程规范意识：清理无关文件、移除明文密钥、补充说明文档、做基本运行测试。

## 技术栈

- **前端**：HTML + CSS + 原生 JavaScript，无后端、无构建工具，静态托管即可运行。
- **大模型**：DeepSeek API（部分作品同时使用硅基流动 API）实现对话、工具调度与回答生成。
- **地图数据**：高德开放平台 Web 服务 API，提供地点搜索、周边检索、路径规划、天气查询、IP 定位、地理编码与静态地图。
- **本地存储**：浏览器 localStorage 保存用户自行填写的 API Key 与会话配置。

## 实践流程

1. **需求澄清**：明确「出行助手」要解决的问题，列出地点、路线、天气等核心场景。
2. **原型搭建**：用 HTML/CSS 完成对话区与地图/结果区的基本布局。
3. **智能体实现**：设计工具函数与提示词，让大模型在需要时调用地图工具，再把真实数据整理成中文回答。
4. **迭代优化**：补充快捷提问、结果卡片、错误提示、移动端适配等体验细节。
5. **规范化交付**：删除与课程无关的文件，清空硬编码密钥，补充 `.gitignore` 与项目说明。
6. **验证与发布**：启动本地静态服务器逐项运行测试，确认可用后再推送到代码仓库分支。

## 安全与隐私约定

- 课程说明文档不记录任何学生个人信息。
- 学生作品分支名称一律使用**姓名拼音全拼**，不包含汉字姓名的分支名。
- 所有源码中的明文 API Key 已清空，仅在运行时由使用者通过页面设置自行填写。
- 用于归档的原始压缩包可能包含历史明文 Key，仅作本地留存，不纳入仓库。
- 历史上出现过的 Key 应在公开仓库前由平台侧撤销或重置。

## 仓库使用说明

- `main` 分支：本课程说明。
- 其他分支：学生作品，每个分支包含一个完整、可独立运行的出行助手项目，分支根目录为 `index.html`。
- 运行任一作品：在该分支目录执行 `python -m http.server 5173`，浏览器访问 `http://localhost:5173/`，在页面「API 设置」中填入自己的 Key 即可对话。
- 请勿使用 `file://` 直接打开页面，否则模块加载与跨域请求会异常。
